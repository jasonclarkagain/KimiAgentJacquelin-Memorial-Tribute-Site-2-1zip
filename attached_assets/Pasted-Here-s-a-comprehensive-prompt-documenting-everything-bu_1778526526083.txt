## Project: Living Memorial for Jacquelin Anne Hellenberg (Jackie)

### What Was Built

A production-grade React + Vite + Tailwind CSS memorial website that evolves into a **living canvas** where visitors can share memories, photos, videos, and messages. The site features automatic seasonal theming that changes visual effects throughout the year.

---

### Tech Stack
- **Node.js 20**, **Vite v7.2.4**, **Tailwind CSS v3.4.19**
- **GSAP + ScrollTrigger** for pinned scroll sections and animations
- **shadcn/ui** component library (40+ components available)
- **LocalStorage** for client-side memory persistence
- **HTML5 Canvas API** for seasonal particle effects

### Section Architecture (6 sections)

1. **HeroSection** — Full-viewport pinned. Circular portrait of Jackie, name, dates (1952–2024), tagline, scroll indicator. Color field backgrounds. GSAP entrance timeline + fade-out on scroll.

2. **ArtworkSection** ("Her Spirit") — Full-viewport pinned. Large framed portrait with authentic story about Jackie's life, her sister Loren, her mother, and best friend Hillary Rice. Stats: 72 Years, ∞ Hearts Touched, 1 Unforgettable Smile.

3. **FamilySection** ("Her People") — Full-viewport pinned. 4 portrait cards: Her Mother, Loren (with grayscale + "In Memory" badge), Hillary Rice (Best Friend), Young Jackie. Real photos with hover color overlays.

4. **GallerySection** — Full-viewport pinned, dark void background. Masonry grid of all 8 photos. Hover labels. **Click-to-expand lightbox** for full-size viewing. Grayscale-to-color hover transition.

5. **LivingCanvasSection** — **NOT pinned** (scrollable for form interaction). The community space. Seasonal background tint. Contains the MemoryFeed component.

6. **UploadSection** — Full-viewport pinned. Legacy memory submission form with name, email, text, photo upload, confirmation state.

### Seasonal Engine

**Auto-detects current season** based on month and applies subtle theme shifts:

| Season | Months | Primary Color | Particle Effect |
|---|---|---|---|
| Spring | Mar–May | Aqua `#7EC8C8` | Floating pink petals |
| Summer | Jun–Aug | Teal `#5BA8A8` | Golden sun sparkles |
| Autumn | Sep–Nov | Rust `#C96A50` | Falling amber leaves |
| Winter | Dec–Feb | Ice `#A8D8EA` | White snowflakes |

- **CSS custom properties** injected at `:root` — all components react to `var(--season-primary)`, `var(--season-secondary)`, etc.
- **HTML5 Canvas particle system** — 30 particles (15 on mobile), floating with sine-wave sway, rotation, opacity variation. `mix-blend-mode: screen` for ethereal effect.
- **Season badge** — Subtle "Spring"/"Summer"/"Autumn"/"Winter" label in bottom-right corner.
- **Reduced motion support** — Particles disabled when `prefers-reduced-motion: reduce` is active.

---

### Design System (Dan Rice / Yves Klein Aesthetic)

- **Typography**: Playfair Display (headings), Inter (body), IBM Plex Mono (labels)
- **Palette**: Cream `#F8F7F4`, Charcoal `#2A2A2A`, Gold `#D4AF37`, Klein Blue `#002FA7`
- **Texture**: SVG noise grain overlay at 3% opacity, `mix-blend-mode: multiply`
- **Navigation**: Fixed top nav with `mix-blend-mode: difference` — works on light and dark sections
- **Scroll Behavior**: GSAP ScrollTrigger global snap — smooth section landing
- **Accessibility**: `prefers-reduced-motion` media query, focus-visible outlines, semantic HTML
