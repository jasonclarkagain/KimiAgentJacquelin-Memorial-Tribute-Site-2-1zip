### The "Living Canvas" Core Architecture

This setup uses a **GPU-accelerated frontend** for the candles and a **memory-safe backend** for the memories.

#### 1. The Dynamic Entry Point (Astro + Three.js)

This script initializes the "Canvas" where the candles will live. It uses a 3D renderer so each flame feels like it has physical weight and light.

```bash
cat << 'EOF' > src/components/LivingCanvas.jsx
import React, { useRef } from 'react';
import { Canvas, useFrame } from '@react-three/fiber';
import { Sphere, MeshDistortMaterial, Stars } from '@react-three/drei';

const Candle = ({ position }) => {
  const mesh = useRef();
  useFrame((state) => {
    mesh.current.distort = 0.4 + Math.sin(state.clock.elapsedTime * 2) * 0.1;
  });

  return (
    <Sphere args={[1, 32, 32]} position={position} ref={mesh}>
      <MeshDistortMaterial color="#ffaa00" speed={2} distort={0.5} />
    </Sphere>
  );
};

export default function LivingCanvas() {
  return (
    <div style={{ height: '100vh', background: '#050505' }}>
      <Canvas camera={{ position: [0, 0, 10] }}>
        <Stars radius={100} depth={50} count={5000} factor={4} />
        <ambientLight intensity={0.2} />
        <pointLight position={[10, 10, 10]} intensity={1.5} />
        <Candle position={[0, 0, 0]} />
        {/* New memories can be mapped here as additional candles */}
      </Canvas>
    </div>
  );
}
EOF

```

#### 2. The Resilient Memory Engine (Rust Axum)

To ensure the site is "Top 25" robust, we use Rust. This backend will handle the high-concurrency of friends and family sharing media simultaneously without the server breaking a sweat.

```bash
cat << 'EOF' > backend/src/main.rs
use axum::{routing::get, Router};
use std::net::SocketAddr;

#[tokio::main]
async fn main() {
    // High-performance router for memories and real-time lighting events
    let app = Router::new()
        .route("/", get(|| async { "The Living Canvas Engine is Online." }));

    // Binds to port 0 to prevent development conflicts in your environment
    let addr = SocketAddr::from(([0, 0, 0, 0], 0));
    let listener = tokio::net::TcpListener::bind(addr).await.unwrap();
    
    println!("Resilience Engine active on: {}", listener.local_addr().unwrap());

    axum::serve(listener, app).await.unwrap();
}
EOF

```
